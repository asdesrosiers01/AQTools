Unit conversion

Common air quality and meteorology unit conversions, in one place

How this works: each card holds two or more linked fields — type in any one of them and the others update immediately. Values aren't persisted or sent anywhere; this runs entirely in your browser.

Concentration: ppm/ppb ↔ µg/m³

Uses the ideal gas law: 1 mole of gas occupies Vm = 0.082057 × T(K) / P(atm) liters. EPA's ambient standard reference condition is 25°C and 1 atm (Vm = 24.45 L/mol); stack testing often uses a different reference — check which one applies before using this for a compliance calculation.

Flow rate: actual ↔ standard cubic feet per minute

ACFM is the actual volumetric flow at stack conditions; SCFM is that same molar flow re-expressed at a fixed reference temperature/pressure. Default reference here is 68°F / 1 atm (EPA Method default); many state programs use 60°F instead — change it if yours does.

Emission rate

tons/year assumes continuous (8,760 hr/yr) operation at the given lb/hour rate — adjust manually for a known annual operating schedule.
